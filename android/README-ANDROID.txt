RADAR V23 ANDROID — by twagirumukiza

Projet Android natif contenant Radar V22 adapté Android.
- Plein écran / paysage
- Sauvegarde localStorage conservée (partie F5 / reprise)
- Vibrations sur destruction et impact
- Bouton Retour Android géré
- Exports JSON vers Téléchargements/Radar
- Aucun accès Internet requis
- Package: com.twagirumukiza.radar
- minSdk 26 / targetSdk 35

OUVRIR / COMPILER
1. Ouvrir le dossier "android" dans Android Studio.
2. Laisser Android Studio synchroniser Gradle.
3. Brancher un téléphone Android (débogage USB) puis Run, ou Build > Generate App Bundles or APKs > Generate APKs.

Le coeur web modifié est également conservé à la racine du ZIP.
